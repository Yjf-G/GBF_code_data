# table_code — source data of the Supplementary Tables

`make_tables.R` regenerates the source data of the Supplementary Tables from the products of the pipeline (`data/output/table_S*.csv` and the intermediate data) and writes them to `data/tables/`. The internal product names `table_S1`–`table_S6` predate the final table numbering; the mapping is given in the table below.

Run it from the repository root:

```sh
Rscript table_code/make_tables.R
```

| Table | Source | Content |
|---|---|---|
| Table 3 | `data/output/table_S2_baseline_regression.csv`, `table_S2_kw.csv`, `table_S2_posthoc.csv`, `data/intermediate/goal_target_ts_global.csv` | The baseline regression and the geographic heterogeneity (the slope/R²/p are the OLS fit of the country-mean baseline series over 2011–2020; the KW test of the slope; the leading continent pair) |
| Table 4 | `data/output/table_S3_trajectories.csv`, `data/intermediate/pgr.csv` | The post-2020 trajectories, the achievement and the classes (with the country-level class counts and the Achievement classes (%) shares of the manuscript column) |
| Table 5 | `data/intermediate/mis_eis_annual_global.csv` | The global MIS/EIS, 2011–2024 |
| Table 6 | `data/intermediate/mis_eis_annual.csv` | The year-on-year paired tests (Wilcoxon with the rank-biserial effect size and the Hodges–Lehmann pseudo-median) |
| Table 7 | `data/intermediate/mis_eis_annual.csv` and `data/intermediate/country_meta.csv` | MIS/EIS by region and development group |
| Table 8 | `data/output/table_S5_csc.csv` | The country synergy contributions (rank and percentile are kept in the source data; the manuscript lists the rows alphabetically) |
| Table 9 | `data/output/table_S6_imputation.csv` and `data/output/endfill_last_observed.csv` | The imputation records, with the columns of the true last observed year and of the endpoint fills (the product of `fig_code/endfill_sensitivity.R`, which has to run first) |
| Table 10 | `data/output/table_S1_projection_models.csv` | The projection models |
| Table 11 | compiled from the country coverage of the pipeline | The countries excluded from the country-level analyses (`data/tables/table_11_excluded_countries.csv`) |

## Conventions

- Table 5 (the global MIS/EIS, 2011–2024) follows the layout of the manuscript: the annual values are given with one decimal ("41.0"), and the "Net change" row is the difference of the displayed values with the percentage computed from the same displayed values (integer per cent when at least 1%, one decimal below that; for example "+3.5 (+11%)", "+6.2 (+15%)", "+0.3 (+0.5%)").
- Table 4: the Class column uses the global-level determination of the manuscript (T6, whose required growth rate is 0, is recorded as "Full achievement"); `class_shares_pct` reproduces the "Achievement classes (%)" cell of the manuscript (Full/Fav./Mixed/Unfav., two decimals, summing to 100.00) and `n_full`/`n_fav`/`n_mixed`/`n_unfav` give the underlying counts.
- Tables 6 and 7 carry the full-precision values; the manuscript displays two decimals (the KS p value is first rounded with `signif(,3)` and then to two decimals).
- Tables 1 and 2 (the list of the 53 indicators and the element alignment) are compiled manually and are therefore not generated by the pipeline; the manuscript is authoritative for them.
- Table 11 is assembled from the indicator-coverage products of the pipeline; the resulting CSV is committed here and is not rewritten by `make_tables.R`.
